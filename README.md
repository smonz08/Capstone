# Capstone
 Eco-House

 Eco-House is a time management game where players must dash around the house to turn off lights, water, and other appliances in order to prevent unnecessary power usage. 
 Players must earn enough Eco-points to fill up the progress bar in the bottom left of the screen. If the progress bar is filled before time runs out then the player will advance to the next level.
 There are 5 levels in the game which increase in difficulty to complete.
 Point System:
 Turning off lights is worth 5 points
 Turning off water is worth 10 points
 Turning off shower and closing fridge is worth 10 points
 Taking too long to turn off items will decrease points by 5

 In order to play the game download the zipped build folder and extract the files. Once extracted click on the Capstone unity file to play.
 The game will open up to the title screen where players can hit the play button to select level and start the game.
